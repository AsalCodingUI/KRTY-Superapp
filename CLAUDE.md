# Kretya Superapp

## UI

Before adding or changing any UI, read `docs/ui/README.md` and the doc for
each component you touch (e.g. `docs/ui/table.md` for any list or table).
Follow its Use / Rules / Don't sections; the live versions are at `/ui`.
Goals: consistent, light, and central (tokens and shared components, not
one-off classes).
